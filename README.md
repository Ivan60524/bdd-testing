# Behavior-Driven Development (BDD) Test Suite - Python & Gherkin

## 📌 Project Overview
This project demonstrates the implementation of **Behavior-Driven Development (BDD)** using Gherkin syntax (`.feature` files) and Python with `pytest-bdd`. It bridges the gap between business requirements and technical test automation, ensuring clear collaboration among stakeholders, developers, and QA engineers.

## 🛠️ Tech Stack & Tools
* **Language:** Python
* **Testing Framework:** Pytest & Pytest-BDD
* **Specification Language:** Gherkin (Syntax)
* **IDE:** Visual Studio Code (VS Code)

## 📁 Repository Structure
* **`user_login.feature`**: Contains business-readable feature descriptions and scenarios written in Gherkin (`Given`, `When`, `Then`).
* **`test_login_steps.py`**: Maps Gherkin natural language steps to executable Python automation functions and assertions.
